## 3. СОПРЯЖЕНИЕ С ФИЗИОЛОГИЧЕСКОЙ МОДЕЛЬЮ И ЦЕЛЬЮ TARGET-CPE45

В SUBJECT-01 действует обязательное требование: **TARGET-CPE45** (сохранение работоспособности на протяжении 2700 секунд при чередовании пиковой нагрузки и восстановления).

### Влияние результатов AEGIS-01 на TARGET-CPE45:
1. **Массовый штраф:** Оптимальная архитектура `ARCH-4` добавляет $+9.2$ кг массы (общая масса 84.2 кг). В соответствии с макромоделью D2 и метаболическими якорями Cycle 8, это увеличивает затраты механической работы локомоции на $11.5\%$.
2. **Базальный метаболизм и ремонт:** BMR возрастает с 86.4 Вт до 95.8 Вт ($+9.4$ Вт непрерывного метаболического расхода).
3. **Терморегуляторное окно:** В отличие от `ARCH-1` (вызывающей тепловой коллапс за 54 минуты при нагрузке 250 Вт), архитектура `ARCH-4` сохраняет 70% площади потоотделения (сброс $>825$ Вт), что гарантирует поддержание гомеостаза на всем интервале 2700 секунд.
4. **Вывод:** Архитектура `ARCH-4` является единственным вариантом биологической защиты, принципиально совместимым с требованиями TARGET-CPE45.

## 4. ИНСТРУКЦИЯ ПО ВНЕДРЕНИЮ (TURNKEY INTEGRATION RECIPE)

Для включения результатов AEGIS-01 в состав единого репозитория `D:\SUBJECT-01` на ветке `research/aegis-01-survivability-20261108`:

```powershell
# 1. Переход в репозиторий SUBJECT-01
Set-Location "D:\SUBJECT-01"
git checkout research/aegis-01-survivability-20261108

# 2. Создание директории исследования
New-Item -ItemType Directory -Path "research\aegis_2026_11_08" -Force

# 3. Копирование расчетного пакета и отчетов
Copy-Item -Path "D:\AEGIS-01\aegis" -Destination "research\aegis_2026_11_08\" -Recurse -Force
Copy-Item -Path "D:\AEGIS-01\*.md" -Destination "research\aegis_2026_11_08\" -Force
Copy-Item -Path "D:\AEGIS-01\data" -Destination "research\aegis_2026_11_08\" -Recurse -Force

# 4. Обновление реестров в D:\SUBJECT-01\registry\
# Поскольку все JSON-массивы используют строго последующие ID, записи просто конкатенируются.
python -c "
import json
for name in ['hypotheses', 'experiments', 'findings', 'negative_results', 'decisions', 'issues', 'sources']:
    main_f = f'D:/SUBJECT-01/registry/{name}.json'
    aegis_f = f'D:/AEGIS-01/registry/{name}.json'
    d1 = json.load(open(main_f, encoding='utf-8'))
    d2 = json.load(open(aegis_f, encoding='utf-8'))
    merged = d1 + d2
    json.dump(merged, open(main_f, 'w', encoding='utf-8'), indent=2, ensure_ascii=False)
"

# 5. Валидация репозитория SUBJECT-01
python tools\validate_repository.py
```
