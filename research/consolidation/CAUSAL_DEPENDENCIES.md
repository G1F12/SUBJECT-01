# Причинные зависимости

Статус относится к одной стрелке и указанному протоколу. Последовательность из разных видов, тканей и задач не наследует причинный статус входных стрелок.

| Откуда → куда | Статус | Область и основание |
|---|---|---|
| Сократительное усилие и ориентация волокон → аксиальная тяга | Поддержано моделью | Проекция через cos α. +2,8° в EXP-0046 задаётся моделью. |
| Тяга и плечо → агонистический момент | Поддержано моделью | Геометрическая механика, параметры индивидуальной силы требуют идентификации. |
| Изменение антагонистического момента → чистый момент | Поддержано моделью | Баланс моментов. В EXP-0046 гамма аппроксимируется из VL, антагонист не измерен. |
| Подавление ко-активации → устойчивый прирост силы при сохранении точности | Гипотетическая | Нужны независимые антагонистические EMG, динамика и наблюдаемые ошибки стабилизации. |
| Модельный мост → превосходство над sEMG в активном коленном протоколе Bird | Опровергнута в указанном сравнении точечных оценок | NEG-0044. Среднее LOSO хуже на 0,0620 R². Популяционный вывод требует независимого набора. |
| Коленный момент → многосуставная функциональная сила, мощность и скорость | Неизвестна | Нет внешнего многосуставного исхода и калиброванного перехода. |
| Анатомический MTJ-компартмент → профиль RNA миоядер | Подтверждена наблюдательно | FND-0047, три внешних донора и отличающиеся анатомические контрасты. |
| MTJ RNA → MTJ-протеом | Подтверждена наблюдательно в части обогащения | FND-0048. Согласование знаков ограничено, функциональный переход не измерен. |
| Нагрузка → активация замороженной MTJ-панели | Неизвестна | NEG-0041, порог не пройден, пол смешан с условием. |
| LOX-транскрипция или productive docking → каталитическая активность | Неизвестна | Нет прямых функциональных измерений в этих проектах. |
| LOX-активность → зрелые сшивки → модуль | Экспериментально поддержана в развивающемся сухожилии цыплёнка | Опубликованные perturbation и механические измерения. Две стрелки ограничены экспериментальной системой. [Первичное исследование](https://pmc.ncbi.nlm.nih.gov/articles/PMC3631620/) |
| Сшивки или модуль → предельная прочность, вязкость разрушения, циклическая долговечность | Неизвестна для предлагаемого изменения у взрослого человека | Возможны разнонаправленные эффекты. Нужны раздельные endpoints. |
| Нагрузка → региональная CSA и структурная жёсткость | Экспериментально поддержана в конкретном протоколе человека | 12 молодых мужчин, 12 недель, две ноги с разной нагрузкой. Модуль в исследовании существенно не изменился. [Первичное исследование](https://pubmed.ncbi.nlm.nih.gov/17524067/) |
| Региональная CSA и тяга → номинальное напряжение | Поддержано моделью | Сила/площадь. При неоднородной геометрии локальное поле и энтезис не определяются одним средним напряжением. |
| Номинальное напряжение и отношение UTS/σ → безопасность в движении | Неизвестна | Не измерены локальные деформации, многокомпонентная нагрузка и усталость. |
| Механическая работа → лёгочный VO₂ | Поддержано моделью и человеческими измерениями в конкретной модальности | ACTES и Malaga. Для Malaga физическая мощность бега недоступна, поэтому связь VO₂ с протоколом скорости не идентифицирует механическую работу. |
| Лёгочный VO₂ → локальная PCr и теплоотведение | Неизвестна по имеющимся данным | EXP-0042–0044. Нужны локальный и тепловой каналы. |
| Метаболическое тепло и теплообмен → накопление тепла | Экспериментально поддержана в протоколе интервальной работы | Прямая и непрямая калориметрия. [Kenny и соавт.](https://pubmed.ncbi.nlm.nih.gov/19204592/) |
| Тепловой и энергетический профили → сохранение мощности, точности и постфункции в CPE45 | Неизвестна | Нет согласованного 2700-секундного внешнего набора по всем звеньям. |
| Модель нейронных цепей дрозофилы → задержки человеческого управления | Неизвестна | Межвидовая проверка отсутствует. |
| Позиционная идентичность аксолотля → восстановление мышечно-сухожильной функции человека | Неизвестна | AXO-PIRA поддерживает ограниченный молекулярный контраст аксолотля. |

Метрики ткани хранятся раздельно. **CSA** — мм², **плотность массы** — кг/м³, **плотность сшивок** — химическое отношение к содержанию коллагена, **структурная жёсткость** — Н/мм, **материальный модуль** и **предельное напряжение** — МПа, **энергия до разрушения** — Дж для образца либо Дж/м³ при нормировке на объём, **усталостная долговечность** — число циклов при заданном спектре амплитуд. У каждой величины отдельный протокол измерения.
