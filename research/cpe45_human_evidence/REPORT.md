# EXP-0139 · CPE45 по данным людей

**CPE45 не подтверждён.** Частичные проверки выявили снижение мощности в коротком интервальном тесте и снижение силы в опубликованной сводке после 45 минут интервальной нагрузки. Ни один проверенный источник не связывает весь обязательный набор измерений у тех же участников в одной 2700-секундной сессии. Канонические пороги и расписание нагрузки остаются открытыми. По правилу DEC-0035 это общий незакрытый критерий для `FORCE20` и `ADAPT25`.

## Чувствительность и проверка моделей

- У Jutlah нижняя граница потери пика при окне 2×2 выше 10% для всех пауз. При сравнении первого и последнего усилия интервалы для 18 и 24 с пересекают 10%. Для средней мощности вывод сильнее зависит от порога. При 12 и 24 с интервал выше 3%, при 18 с включает 3%; все интервалы пересекают 5% и 10%. Средняя мощность из Дж/6 с воспроизвела `Avg` с численной погрешностью. В крайних окнах нет пропусков, доступные пары и полные окна дают одинаковые оценки. Первая попытка часто слабее второй, поэтому окно из одной попытки особенно чувствительно к старту.
- Для McLaughlin средняя разность поздних и ранних минут составляет −12,95, −11,29 и −10,60 Вт при окнах 5, 9 и 11 минут. Ряд показывает нагрузку эргометра в непрерывном тесте и не измеряет предельную работоспособность. По 24 участникам нет пропусков мощности. На 60-й минуте температурная пара доступна у 23, а рост от 1-й минуты равен 1,37 [1,11; 1,63] °C при продолжающейся нагрузке. Отсчёт до начала нагрузки в температурном листе отсутствует.
- Для Norbury через 2700 с падение MVC составляет 6,99 [3,58; 10,33]% (LL) и 6,33 [2,73; 10,19]% (HL), интервалы пересекают границы 5 и 10%. Через 24 ч верхние границы ниже 5%. Разница потерь между 5-й и 45-й минутами составляет 2,01 [−1,18; 5,92] п.п. (LL) и 2,63 [0,49; 4,94] п.п. (HL). Для Goodall интервал потери MVC выше 5% и пересекает 10%, а опубликованная типичная ошибка изменения MVC по точкам 6,3–10,8%. Для Marshall простой интервал из округлённых сводок включает ноль и оба рабочих порога. Он не воспроизводит статистическую модель авторов.
- Воспроизведён закреплённый тест прогноза следующей пиковой мощности Jutlah. На 7 отложенных участниках RMSE D1 и D2 равны 350,70 и 361,71 Вт при 126,54 Вт у константной базы. Парные разности RMSE D1 и D2 к базе [205,99; 242,23] и [197,96; 270,35] Вт. Повтор EXP-0138 дал прежние значения из JSON, включая перенос Evangelidis → Križaj с MAE 72,51 Н·м против 44,97 Н·м у фиксированной базы. Тесты показывают слабый перенос этих моделей в изученных протоколах.
- В поиске найден отдельный 4-часовой crossover Almquist с непрерывным условием, сопоставленным по работе авторами. Первичный отчёт на 12 велосипедистах не выявил различий средней спринтерской мощности между сериями (p=0,6) и изменений валовой эффективности, зависящих от условия (p=0,8). Полученный файл другого исследования Almquist содержит только агрегаты. Без попарных джоулей и сопоставимой батареи эффект распределения работы в CPE45 не установлен. 360 Вт × 2700 с = 972 кДж остаётся отдельным тепловым сценарием. [Первичная работа](https://pubmed.ncbi.nlm.nih.gov/31693997/)

Источники, версии, файлы и причины недопуска перечислены в [SOURCES.json](SOURCES.json). Для воспроизведения положить пять файлов из `inputs` по указанным путям внутри `tmp/` или своего каталога `--data-root`. Хеши сверяются до чтения. Среда расчёта Python 3.12.10, NumPy 2.5.4, openpyxl 3.1.5 и SciPy 1.18.1. Исходные файлы не включены в коммит.

```powershell
python research/cpe45_human_evidence/run.py --data-root tmp --check
python research/recovery_2026_11_04/reproduce.py --check
python research/program_evidence_audit/run_independent_torque_transfer_test.py --output-json tmp/transfer.json --output-md tmp/transfer.md
python tools/validate_repository.py
python -m unittest discover -s tests -p test_cpe45.py
python -m pytest tests -q
```

Для полной проверки нужен один файл на сессию с идентификаторами участника и режима, калиброванной подписанной внешней мощностью либо измеренными силой и сопряжённым перемещением, синхронными силой и кинематикой, метками усилий/пауз, одинаковыми задачами в начале и в конце, траекторными и координационными ошибками, всеми стимулами и ответами. Нужна парная исходная и отдельная постнагрузочная батарея после 2700 с с фактическим временем начала каждого теста. Для сравнения распределения работы нужна непрерывная парная сессия с сопоставимыми джоулями и длительностью. Для решения нужны утверждённые нагрузки, допуски и критерии по каждому каналу. Полный профиль для каждой принятой сессии можно сразу вычислять через `python tools/cpe45.py --input observations.json --output metrics.json` по [формату входа](../targets/COMBAT_LIKE_ENDURANCE_45MIN.md). Групповой анализ затем использует парные контрасты по участникам и те же правила неопределённости.
