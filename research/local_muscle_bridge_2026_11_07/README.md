## 1. Назначение и состав модуля

Модуль реализует трёхслойный измерительный мост между механической мощностью, локальной энергетикой мышцы (³¹P-MRS) и системным газообменом (CPET), математический анализ идентифицируемости и воспроизводимые вычислительные эксперименты на основе реальных рецензированных данных (Moll et al. 2017, Dissertation 2018; Cannon et al. 2014, PMC4262339).

### Структура файлов:
- `PLAN.md` — План исследования Cycle 7 и перечень задач.
- `REPORT.md` — Итоговый проверенный научный отчёт Cycle 7.
- `DATA_AUDIT.md` — Метрологический аудит источников данных, категоризация и верификация лицензий.
- `MATHEMATICS.md` — Строгие аналитические доказательства симметрий и анализ рангов FIM.
- `MEASUREMENT_MODEL.md` — Архитектура трёхслойного измерительного моста с разделением задержек.
- `LIMITATIONS.md` — Физиологические, измерительные и модельные ограничения, протокол отзывов.
- `acquire.py` — Скрипт воспроизводимого сбора метаданных и аудита источников.
- `digitize_moll_data.py` — Оцифровка и структурирование проверенных данных Moll 2018 и Cannon 2014.
- `moll2018_extracted_measurements.json` — Оцифрованные таблицы, литературные корреляции и приближённые диаграммы.
- `identifiability.py` — Численный анализ SVD, Якобиана, FIM и Profile Likelihood.
- `identifiability_results.json` — Результаты анализа идентифицируемости M1–M7.
- `experiments.py` — Вычислительные эксперименты EXP-0027..EXP-0031 с аудитом и исправлениями.
- `experiment_results.json` — Проверенные итоги экспериментов EXP-A..EXP-E.
- `test_local_bridge.py` — Модульные тесты физических инвариантов, аудита чисел и непротиворечивости отчёта.
- `manifest.json` — Контрольные суммы SHA256 всех артефактов цикла.

## 2. Воспроизведение вычислений и тестов

Все команды запускаются в корневой директории репозитория:

```powershell
# 1. Оцифровка и проверка согласованности данных
python research/local_muscle_bridge_2026_11_07/digitize_moll_data.py

# 2. Анализ идентифицируемости (SVD, FIM, Profile Likelihood)
python research/local_muscle_bridge_2026_11_07/identifiability.py

# 3. Запуск проверенного экспериментального комплекса (EXP-0027..EXP-0031)
python research/local_muscle_bridge_2026_11_07/experiments.py

# 4. Запуск модульного тестирования измерительного моста и аудита
python -m unittest discover -s research/local_muscle_bridge_2026_11_07 -p "test_*.py"

# 5. Сквозная валидация всего репозитория
python tools/validate_repository.py
```
