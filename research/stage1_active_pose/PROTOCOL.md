# EXP-0147 · Активное сравнение в фиксированной изометрической позе

База `87b0a8f9bcc43335471a1675a345849ff96c16a0`. Правила записаны после проверки структуры публикаций и до итогового расчёта.

1. Первичный исход Kubo–Ishigaki — измеренный момент подошвенного сгибания при 10° подошвенного сгибания голеностопа и разогнутом колене, 0–12 недель, ISO против PLY. Берём опубликованные средние и SD индивидуальных относительных изменений, потому что ноги назначены случайно в пределах участника. 1RM PLY и MVC ISO из регулировки нагрузки различаются по исходу и исключаются из общего контраста. Тканевая рампа при 0° остаётся отдельной конфигурацией.
2. Для ADAPT25 проверяем положительную нижнюю границу темпа контроля и контраста `ISO−1,25×PLY`. Двусторонний 95% t-интервал рассчитываем для всех допустимых межножных корреляций от −1 до +1 и проверяем округление опубликованных процентов до 0,1. Для FORCE20 отдельно оцениваем индивидуальный прирост и разность относительно активной ноги. Отношения средних из Table 1 служат проверкой точечных оценок.
3. Для тканевой части сохраняем нативное пиковое удлинение, жёсткость и площадь поперечного сечения. Рамповую и быструю пробы анализируем отдельно. По средним и SD при неизвестной парной ковариации оцениваем условный интервал изменения и самую высокую совместимую с ним верхнюю границу прироста удлинения. Коэффициент жёсткости не подставляем вместо локальной ёмкости. Сопоставимость дозы и наличие ранних визитов проверяются отдельно для ADAPT25.
4. Для исследований нескольких активных протоколов фиксируем первичное сравнение одинаковой недельной экспозиции, если она предусмотрена, и описательно показываем остальные. Если ковариация ног и составы пар не опубликованы, допустимы огибающие стандартной ошибки без предположения о независимости. Публикация и поправка описывают одну когорту. CPE45 вне области расчёта.
