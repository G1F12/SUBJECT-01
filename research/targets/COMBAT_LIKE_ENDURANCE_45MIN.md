# TARGET-CPE45 — COMBAT-LIKE PERFORMANCE ENDURANCE

Дата принятия требования: **2 ноября 2026**. Интеграция и проверка: **3 ноября 2026**.
DEC-0007; открытая проблема ISS-0011. Машинная спецификация: [CPE45.json](CPE45.json).

## Место в проекте и научный статус

TARGET-CPE45 дополняет главную цель SUBJECT-01 — максимальное комплексное
расширение возможностей организма. Образ «сильнейшего»/Сатору Годжо служит
мотивацией, а не физической спецификацией или доказательством достижимости.
Внешний экзоскелет не считается конечным решением.

Обязательная исследовательская цель: сохранять чрезвычайно высокую комплексную
физическую работоспособность **2700 секунд**, чередуя взрывные/субмаксимальные
действия и короткое восстановление. Это не непрерывная абсолютная максимальная
мощность. Численные амплитуды нагрузки, duty cycle, критерий «короткого» отдыха,
пороги сохранения и точки post-наблюдения пока **не калиброваны** и не назначены.

Не заявляется, что современный человек или предложенная архитектура достигают
этой цели. Синтетические тесты подтверждают только арифметику измерительного кода.
NO_GO для биологических вмешательств сохраняется. Медицинская безопасность,
повреждение/устойчивость тканей и сохранность сердечно-сосудистой системы не
выводятся из одной механической работы или отсутствия падения мощности.

## Измеримые конечные точки

| Характеристика | Измерение | Что нельзя заключить автоматически |
|---|---|---|
| Работа | Интеграл подписанной внешней мощности по времени; отдельно положительная/отрицательная работа, J | Метаболическая энергия, КПД и безопасность не измерены этим интегралом |
| Взрывной выход | Средняя/наблюдаемая пиковая мощность каждого усилия; N, W | Между отсчётами истинный пик неизвестен |
| Сила/скорость | Средняя и пиковая сила, средняя/пиковая скорость, путь | Модуль силы × скорость не равен мощности без направления и точки приложения |
| Ускорение/манёвр | Знаковые extrema ускорения; время задачи и траекторная ошибка в m | Одной скорости недостаточно для доказательства манёвренности |
| Реакция/точность | Latency всех ответов и правильных ответов отдельно; correct/все стимулы, включая omissions | Быстрая ошибка не улучшение реакции; отсутствие trial не нулевая latency |
| Координация | Временное среднее task-defined ошибки в m | Разные виды координации нельзя сводить к общему баллу без валидации |
| Падение выхода | late/early, (early−late)/early и абсолютная разность, по одинаковому task_id | Изменение demand/мотивации/методики не идентифицирует физиологический механизм |
| Восстановление | Длительность отдыха и изменение следующего сопоставимого усилия; возврат к раннему reference | Это наблюдаемый отклик, не скорость ресинтеза PCr или установленная tau |
| После 45 минут | Отдельные post-отсчёты с абсолютным временем >2700 s и сопоставимым task_id | Конечный отсчёт t=2700 не отдельный post-тест; отсутствие post не означает сохранность |

Это объективные показатели **performance fatigability**, а не полная оценка
субъективного утомления. Самоотчёт/RPE и клинические/тканевые измерения требуют
отдельных каналов и протоколов; данный модуль их не заменяет (SRC-0030).

## Контракт данных и воспроизводимое вычисление

Модуль `tools/cpe45.py` использует только стандартную библиотеку Python.
API: dataclass `Sample`, `Episode`, `Trial` и функция `analyze`.

Входной JSON для CLI:

- `samples`: список объектов с **всеми** полями Sample из CPE45.json.required_units,
  кроме latency/accuracy: time_s, power_W, force_N, speed_m_s, acceleration_m_s2,
  coordination_error_m, maneuver_error_m. Строго возрастающее время от 0 до 2700 s.
- `episodes`: start_s, end_s, kind (`effort`/`recovery`), task_id; полное разбиение
  [0,2700] без пропусков/перекрытий, оба типа присутствуют. Расписание задаёт
  исследовательский протокол; не определяется произвольным power threshold.
- `trials`: time_s предъявления, task_id, latency_s, correct, omitted (по умолчанию false).
  При omission: latency_s=null и correct=false. Пропущенное неизвестное значение
  без явного omission недопустимо. Trials строго возрастают; одновременные стимулы
  нужно разделять на отдельные анализы, не искусственно сдвигать время.
- `protocol`: early_end_s, late_start_s, max_gap_s — обязательные явные параметры,
  окна не перекрываются. В каждом окне нужен хотя бы один целый effort.
- Необязательно `post_samples` и `post_task_id`: отдельный ряд строго после 2700 s.
  Без него статус post=`not_measured`. Один post-отсчёт — точечное измерение:
  длительность и работа равны нулю, не вымышленный post-интервал.

```text
python tools/cpe45.py --input observations.json --output metrics.json
python -m unittest discover -s tests -p test_cpe45.py
```

Координатные системы, определения ошибок, нагрузка, инструменты, частота,
аппаратная latency, калибровка, неопределённость, среда, источник/версия и права
наблюдений должны храниться рядом с входным JSON в протоколе исследования.
Метрики сами не подтверждают качество приборов и клиническую пригодность данных.
При частичном покрытии 2700 s модуль выдаёт ошибку, а не «полный» результат.
NaN/inf/null/строки/boolean вместо физических чисел, неизвестные значения,
нестрогое время и разрывы больше max_gap_s отклоняются; нет imputation.

Сигналы интерполируются кусочно-линейно только внутри допустимых разрывов;
интегрируются трапециями с точным разделением пересечений power=0. Нет экстраполяции.
Эпизодные средние взвешены временем; средние ранних/поздних **эпизодных** показателей
взвешены числом эпизодов. Сравнение работы эпизодов возможно только при одинаковой
длительности. Task_id обязан кодировать сопоставимые инструкции/внешние требования:
совпадение строки программой не доказывает реальную сопоставимость.
Несопоставленные task_id перечислены отдельно. Стимулы на границе относятся
к следующему интервалу; последний t=2700 входит в основной результат.

При нулевом reference отношение и относительное падение равны null, а не inf/0.
Потенциация сохраняется как отрицательное падение, без обрезания.
Для ошибки/latency уменьшение — улучшение; нельзя трактовать знак relative_drop
как ухудшение независимо от типа показателя. Reaction summary содержит числа
стимулов/omissions и знаменатель accuracy; missing trials дают null.
Restored fraction=(next−previous)/(early_reference−previous) не обрезается;
при нулевом знаменателе null, возможны overshoot и отрицательные значения.
Post не добавляется к работе первых 2700 s; сравнивается только с тем же ранним task_id.
Результат всегда содержит `target_achievement=not_assessed` и
`physiological_validation=false`; модуль не рассчитывает вероятность успеха.

## Многокритериальная оптимизация и следующий цикл

TARGET-CPE45 — самостоятельный обязательный вектор: абсолютный выход при
сопоставимом demand, сохранение силы/мощности/скорости, latency **совместно**
с accuracy/координацией, восстановление и отдельная post-функция.
Не вводятся универсальные веса и сводный «боевой балл». Низкая начальная
производительность с высоким retention не считается достаточным результатом.

EXP-0001…0010 и их Pareto-таблицы **не изменяются** и имеют статус по новой цели
`not_assessed`. Они не становятся удовлетворяющими TARGET-CPE45 из-за принятия DEC.
До калибровки/проверки нового критерия оптимизатор обязан оставлять статус unknown,
а не пропускать отсутствующий endpoint как автоматически допустимый.

**Следующая исследовательская задача:** разработка динамической модели утомления
и восстановления на 2700 s с сопряжением энергетики, кислорода, теплообмена,
силоскоростных ограничений, управления и post-функции. Подобрать независимые
данные и неопределённости; сохранить прежние калибровочные блокеры. Эта модель
**не разработана в рамках текущей интеграции**. Сейчас выполнены регистрация
требования и проверяемая измерительная система, без нового EXP/биологической валидации.
