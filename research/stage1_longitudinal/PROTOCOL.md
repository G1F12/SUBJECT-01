# EXP-0143 · Продольные записи силы и ткани

Базовый коммит `05ebfd6656c299a1c62a0ad90fb4705f35a6dbed`. Исходы опубликованы и были видны при скрининге. Ниже правила повторного расчёта до оценки эффекта.

1. Для Weidlich основной исход — момент разгибания колена относительно массы по Table 1. Сезонный спортивный контроль активен. Для каждого плеча оцениваем линейный тренд по всем четырём визитам на опубликованной приблизительной шкале недель. Нормируем на исходное среднее, после чего вычисляем `I−1,25×C` в п.п./нед. Повторяем по началу и концу и на общей шкале визитов 0/12/24/36 как проверку влияния расписания. Из-за отсутствия исходной ковариации показываем широкие пределы интервалов: линеаризуем нормировку и в каждом плече ограничиваем SD контраста суммой взвешенных маргинальных SE, после чего складываем дисперсии независимых групп. Для малых выборок берём минимальное число степеней свободы, равное минимальному n по визитам минус один. У контроля меняющиеся составы визитов, поэтому результаты относятся к групповым средним. Точные темпы по участникам из этих сводок не идентифицируются.
2. Для Weidlich Fig. 3A и Fig. 4A проверяем, достаточно ли цвета и линии для связи показателей. Цифровая реконструкция пригодна для описания опубликованных точек, если для выбранного плеча обе шкалы имеют однозначную калибровку и видны все пары с уникальным цветом. Сохраняем координаты и границы погрешности. При слиянии точек без надёжного разрешения используем только сводки и опубликованную долю участников с высокой деформацией. Порог ≥9% характеризует высокий уровень деформации в статье, а не предел разрушения.
3. Для Eriksen основной исход — пиковый суставной момент на Fig. 2A, с умеренной активной группой для ADAPT25 и отдельной группой без тренировки для диагностической поправки FORCE20. Оцифровываем столбики и верхние SE по двум подписанным отметкам оси. Для pre/post вычисляем относительное изменение и интервал с неизвестной парной ковариацией. Проверяем чувствительность к ±1 пикселю для высоты и колпачка SE. По Table 2 анализируем максимальную деформацию и расчётную нагрузку сухожилия при отдельной изометрической рампе. Сводки биопсии не определяют индивидуальный запас.
4. Для McMahon читаем исходные значения момент/жёсткость из S1, без усреднённых строк. Строка связывает pre/post и блоки данных только при совпадении кодов внутри строки. Повторяющийся код между строками остаётся неоднозначным. Помимо рабочего анализа всех восьми строк сверяем все возможные варианты исключения одной неоднозначной строки и обеих. S2 годится для проверки повторения данных, но не как независимая когорта. Показываем средний индивидуальный процент и процент изменения средних с 95% ДИ. Половое наблюдательное сравнение групп с одной экспозицией не считаем проверкой новой нагрузки против сопоставимого активного контроля. Группы без тренировки не реконструируем из отсутствующей таблицы. Жёсткость при относительном максимуме не интерпретируем как тканевой запас. Проверяем, к какому из двух максимумов относились проценты по методам статьи.
5. Для Rieder основная диагностика — изометрический момент HSR против активного WBV и отдельно ожидающего контроля. При отрицательном темпе WBV отношение темпов неинтерпретируемо. Сохраняем поправку против ожидающего контроля и доступный интервал по клиническим исходам как отдельный результат. Клиническая популяция и разные нагрузки ограничивают перенос.
6. Не объединяем оценки разных когорт и разных движений. Для жима под углом колена 140° нужна пара максимальных усилий со связанными тканями в той же конфигурации. При отсутствии такой пары результаты изометрического разгибания колена остаются самостоятельными. CPE45 вне этапа.
7. Для Bogdanis используем опубликованные изменения пиковой силы по номинальным углам при неизменной позе. Сохраняем абсолютное превышение точки над +20% и вычисляем максимально допустимый прирост активного контроля для прохождения каждого порога по точечной оценке. Средний прирост контроля по всем углам обозначаем как диагностический сценарий, не подставляем его вместо измерения при 146° или 162°. Без SD и ковариации изменения на нужном угле не восстанавливаем ДИ из Tukey p для отличия от нуля. Значение 140° не интерполируем.
