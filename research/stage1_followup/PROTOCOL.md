# Этап 1 · проверка совместных данных силы и тканей

Продолжение EXP-0140, исходный коммит `6dc21c5`. Протокол ретроспективный. Правила расчёта зафиксированы до новых контрастов. Для ADAPT25 нижняя граница 95% ДИ для `темп AEL − 1,25 × темп TRAD` должна быть выше нуля при уверенно положительном темпе TRAD. Для FORCE20 нужен прирост не менее 20% при сопоставимой массе и достаточный тканевый запас в том же сценарии. Оба пути требуют связанных измерений ткани.

## ADAPT25

Сначала связываем публикации Walker по описанию когорты, групп, протокола и срокам. Основной исход — максимальный произвольный изометрический момент разгибания колена в Н·м, в опубликованных сводках — индивидуальное изменение относительно начала каждого интервала. AEL сравнивается только с TRAD, получившей тот же общий контролируемый курс с другой эксцентрической нагрузкой. Окно 0–10 недель основное, 5–10 недель заранее определённая проверка нелинейности. 10 недель тренировок и 11–12 календарных недель между соответствующими тестами показываем как чувствительность к срокам тестирования около недельной разгрузки. Для 5–10 недель сохраняем одинаковую задержку визитов после соответствующих тренировочных блоков. Для сводок рассчитываем интервалы Стьюдента для темпа и Welch для межгрупповой линейной комбинации из опубликованных N, средних и SD индивидуального изменения. Учитываем округление до точности исходных чисел. Окна считаются отдельно. Общую ковариацию окон без индивидуального файла не восстанавливаем.

Публикация 2020 года анализируется по тому же курсу, а не как независимая репликация. Сравниваем жёсткость при прежнем абсолютном верхнем усилии и при новом относительном уровне отдельно, гистерезис отдельно. Указываем, что перемещение на УЗИ и момент на динамометре наблюдаемы, оценка силы сухожилия зависит от плеча момента, а предел разрушения не измеряется. Если доступны лишь средние и SD до/после, сравниваем изменения с неизвестной корреляцией `r` между визитами, показывая диапазон интервалов для `r = −1, 0, 0,5, 0,9, 1`. Для графиков с ненумерованными точками нет совместимой привязки участников между исходами. Графики подтверждают доступность индивидуальных распределений; нельзя соединять точки по вертикальному порядку или присваивать совпадающий ID. Число включённых точек по исходам должно соответствовать табличному N, иначе выводы по среднему и SD опираются на опубликованную таблицу.

Дополнительный активный контроль Massey. Сопоставляем SCT и ECT на одном тесте MVT за 12 недель. Для опубликованных пред- и пост-средних масштабируем разность групповой исходной величиной, фиксированной в расчёте. Это условная оценка по сводным данным. `r` варьируется независимо от вывода авторов о нулевом межгрупповом различии. Используем N из примечания под таблицей для каждого отдельного показателя. По деформации и жёсткости считаем абсолютное изменение у групп. Изменение при одинаковой прежней силе не измеряет допустимую нагрузку в новом максимуме.

## FORCE20

Приоритет — двусторонний максимум жима при внутреннем угле 140° (40° сгибания) и сопоставимая проверка 100°. Используем фиксированные базовые прогнозы EXP-0090 для абсолютной силы. Для внешнего источника без полных индивидуальных сессий первичен знаковый сдвиг «модель минус среднее» и 95% ДИ из опубликованных N и SD. Дополнительно RMSE константного прогноза вычисляем из первого и второго моментов выборки. Для опубликованного графика Bland–Altman допускается отдельная диагностическая проверка по читаемым маркерам с `S2 = mean + difference/2`, `S3 = mean − difference/2`. Фиксируем оси, центры, неразрешимые наложения и сверяем число и сводки с таблицей. Сопоставляем фиксированную модель с LOSO-средним остальных наблюдённых людей на том же угле и с прогнозом S3 по S2, если возможно. При неполной оцифровке сообщаем расчёт только на подмножестве и проверяем чувствительность к ошибке чтения и опубликованной полной выборке. Бутстрэп по удержанным наблюдениям фиксирует рассчитанные прогнозы. При отсутствии явного ID между углами разности по людям между позами не вычисляем.

Изменение позы от 100°/110° к 140° даёт угловую зависимость, а повтор той же позы — воспроизводимость. Проверка +20% относится к изменению состояния в одной позе при сопоставимой массе и технике. Тканевую чувствительность 140° считаем только в зафиксированной сетке EXP-0090. Массу, геометрию, локальную деформацию и разрушающую нагрузку не восстанавливаем из графика внешней силы. Номинальные прогнозы на участниках с другой конфигурацией установки проверяют перенос фиксированного номинала, а не индивидуально геометризованной модели.
