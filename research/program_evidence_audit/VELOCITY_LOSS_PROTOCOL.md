# EXP-0080 — перенос зависимости потери скорости от доли завершённого подхода

Предварительный протокол, до расчёта исходов: открытый CSV Iglesias-Soler et al., Zenodo 15556672, только жим ногами, 23 женщины после менопаузы, по одному набору строк на Subject; файл содержит 227 строк и пять столбцов, несмотря на описание шести с Session. Первые доли разнятся и отсутствуют ранние повторения; отбор и метод измерения требуют первоисточника. Набор не содержит силу, абсолютную скорость, геометрию и температурные данные. Каждый Subject удерживается целиком.

Гипотеза: известная **после окончания подхода** доля завершения PercMNR предсказывает PercVL на удержанной участнице точнее константы. Модель: линейная регрессия PercVL на PercMNR, обучение на остальных людях. База: среднее PercVL обучающих участниц с равным весом каждого человека. Регрессию также обучать с весом 1/n строк участницы. Основной исход: средняя по участницам MAE, сравнение модели и константы; дополнительный RMSE и смещение; 95% percentile bootstrap парного выигрыша MAE, 10000 повторов, seed 20261120, ресэмплировать участниц. Интервал полностью выше нуля означает лишь преимущество в этой выборке. Вторичный результат — наблюдаемый диапазон и межучастническое SD PercVL при PercMNR=100. Строки без конечного значения исключаются и подсчитываются. Оценки являются исследовательскими, ранее не ослеплёнными.

Доля PercMNR зависит от уже известной финальной длины подхода, поэтому это ретроспективная проверка связи, не прогноз оставшихся повторений онлайн и не тест модели восстановления или динамической силы. Никаких порогов функционального улучшения и выводов об архитектуре A из этой проверки. Отрицательный результат не доказывает отсутствия зависимости.
