# Аудит функционального набора du Plessis

Проверено 20.11.2026. [Первичная статья](https://doi.org/10.1371/journal.pone.0259034) описывает 16 тренированных велосипедистов, 2- и 4-минутные испытания и мощность 10-секундного спринта до и после нагрузки. Это измеряемая утомляемость и функциональная мощность. Длительное восстановление и 45-минутная комплексная работоспособность этим протоколом не покрываются.

[Dryad v1](https://doi.org/10.5061/dryad.76hdr7sxv), CC0, API версии 177410 сообщает файлы 2and4minData.csv, PreVsPost_Peak_Power.csv и README. SHA-256 первого файла 2b7f45067588481082d8db72624c59879db1a3781a0cc23a21f3fab00ccc4f3e, второго 729703f11ec3bd608e0d870bebdcfee43d685e7fe74319b3ec116bf159ac9c55, README ae3ad0283bfb2d99dd0ad8c17a2021800fca7ae92c0ea94393ffb4261dd4a2cd. Метаданные доступны через `https://datadryad.org/api/v2/versions/177410/files`. Прямой API download ответил HTTP 401, публичный file_stream HTTP 403. Исходные таблицы в этой среде не получены и модель не оценивалась.

Публикация сообщает среднее снижение пиковой мощности на 32% и 47% после двух разных длительностей нагрузки. Эти значения сохранены как контекст опубликованной работы, а не как повторный расчёт SUBJECT-01. Исходы на одного человека доступны только после загрузки таблиц и проверки их разметки. [Zenodo 5560160](https://zenodo.org/records/5560160) содержит открытый код авторов, но два Rmd без исходных таблиц.

## Протокол продолжения после получения таблиц

Сверить версии и SHA-256, лицензию и словарь полей, соответствие 16 участникам и единство идентификаторов между 2 и 4 минутами. До анализа исходов зафиксировать сценарий LOSO: для удержанного участника предсказывать измеренный индивидуальный спад пиковой мощности после 4 минут из исходной мощности и измерений 2-минутной сессии. Сравнить с обученным только на оставшихся участниках средним спадом и линейной моделью. Внутренний выбор регуляризации, заполнение пропусков и преобразования выполнять внутри обучающего фолда. Сообщать MAE в ваттах и процентах, парные ошибки и кластерный интервал по участникам. Учитывать порядок сессий, время отдыха и различия нагрузки, если указаны. Предсказание для нового участника применимо лишь при доступных входах его 2-минутной сессии.

Для переноса к CPE45 понадобятся связанные измерения в 2700-секундной задаче, траектория повторных усилий и последующая функция. Текущий набор может проверить кратковременную утомляемость, сравнение моделей и наблюдаемость мощности.
