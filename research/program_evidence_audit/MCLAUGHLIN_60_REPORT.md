# EXP-0086 — более длинная проверка температурного прогноза

[Протокол](MCLAUGHLIN_60_PROTOCOL.md), [результаты](MCLAUGHLIN_60_RESULTS.json), источник [SRC-0086](https://doi.org/10.6084/m9.figshare.29120024.v1). Допущены 23 участника, один исключён по правилам наличия и качества. Температура ректальная, среда зафиксирована по срезу 5–6 минут; мощность подаётся поминутно при условной трактовке числовых меток как концов интервалов. Оценка повторно использует когорту и прежние результаты до 45-й минуты; данные 60-й минуты уже участвовали в допуске. Это не ослеплённая новая когорта и не оценка CPE45.

| Модель | MAE изменения 60−1 мин, °C | MAE изменения 60−45 мин, °C |
|---|---:|---:|
| Температура без изменения | 1,376 | 0,250 |
| Многослойная, поминутная мощность | 0,733 | 0,329 |
| Многослойная, постоянная первая мощность | 0,900 | 0,362 |
| Однокамерный баланс, поминутная мощность и масса участника | 1,078 | 0,318 |

Для полного окна парный выигрыш многослойной модели с переменной мощностью относительно постоянного прогноза — **0,643 °C**, бутстрэп 95% **[0,227; 0,972]**; относительно однокамерной модели — **0,345 °C [0,145; 0,520]**. В последнем 15-минутном участке разница «постоянный прогноз минус многослойная модель» составляет **−0,078 °C [−0,198; 0,026]**: превосходство многослойного прогноза не установлено. Однокамерный контроль предсказывает среднюю температуру, а наблюдается ректальная; это существенное различие исхода.

Для окна 1→60 мин средняя механическая работа при поминутных значениях **582,0 кДж**, при использовании первой мощности весь период — **614,3 кДж**. Полная модель с переменным входом имеет среднее смещение +0,377 °C. Для последних 15 минут модель продолжает внутреннее состояние, рассчитанное с 1-й минуты; наблюдение 45-й минуты применяется для определения исхода и начальной точки постоянного прогноза, а не для подгонки состояния тепловой модели. Следовательно, сравнительный результат относится именно к этой схеме.

Модельный баланс проходит порог 0,01 Дж; однокамерный расчёт сверяется с теми же уравнениями существующего контроля на обоих горизонтах при индивидуальной массе. Ссылка на работу, скорость, точность и post45 отсутствует. Результат не меняет `TARGET-CPE45 = NOT EXTERNALLY VALIDATED` и не устанавливает эффективность или безопасность архитектуры. Следующий шаг — новые удержанные данные с измеренными начальными состояниями и средой, затем совместная проверка механических и функциональных исходов.
