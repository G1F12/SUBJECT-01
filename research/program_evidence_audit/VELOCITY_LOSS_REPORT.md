# EXP-0080 — ретроспективная связь скорости и выполненной доли

Источник [SRC-0088](https://doi.org/10.5281/zenodo.15556672), открытый набор Iglesias-Soler и Rial-Vázquez, версия 1, лицензия CC BY 4.0, файл leg press, MD5 издателя `d9508e0027755f1ed30cc9d4cbed5b34`; скачанные байты SHA-256 `9283595449be5d7a3ed1641d2ba1f6919288907805df9888098680df022bd3ad`. Воспроизведение: скачать файл `%VL_%NRM_LEG PRESS.csv` по ссылке Zenodo и выполнить `python research/program_evidence_audit/run_velocity_loss.py <путь-к-CSV>`. Сырые строки в репозиторий не внесены. [Протокол](VELOCITY_LOSS_PROTOCOL.md) записан до вычисления итогов; [JSON](VELOCITY_LOSS_RESULTS.json) хранит хеши. Прочитаны метаданные, README и структура CSV, полный текст статьи и независимый аудит измерений не проверены.

23 участницы, 227 строк; исключений по отсутствующим/нечисловым значениям нет. Обучение линейной регрессии на остальных участницах с равным весом человека дало MAE **9,16 п.п.** против **11,86 п.п.** у константы; средний парный выигрыш **2,70 п.п.**, 95% бутстрэп по участницам **[1,60; 3,80] п.п.**. RMSE 11,49 против 14,10 п.п. По конечной точке 23 значения, диапазон потери скорости **11,9–59,8%**, SD 11,32 п.п. Это исследовательская внешняя проверка описания внутри одной выборки, а не проспективно ослеплённая проверка. Межвыборочный перенос неизвестен.

Доля PercMNR определена через уже известное итоговое число повторений: модель нельзя применять для прогноза оставшегося числа в процессе подхода. В CSV пять колонок и нет Session, хотя README заявляет шесть; часть ранних значений отсутствует, причины не выяснены. Восстановление, CPE45, сила, абсолютная мощность, тканевая нагрузка, перенос на мужчин и другие группы не измерены. Данные показывают необходимость учитывать индивидуальную вариативность скоростной деградации при формировании требований к динамической модели; они не подтверждают изменение здоровья или преимущества архитектуры A и не заменяют совместную кинетику/кинематику.
