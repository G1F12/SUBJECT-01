# EXP-0081 — динамическая связь при приседаниях

[Протокол](SQUAT_TRANSFER_PROTOCOL.md) и [результат](SQUAT_TRANSFER_RESULTS.json). Источник [SRC-0089](https://doi.org/10.35090/gatech/70296), статья [Scherpereel et al.](https://doi.org/10.1038/s41597-023-02840-6), открытые измерения 12 здоровых молодых участников в одном центре, лицензия CC BY 4.0. Углы вычислены по маркерам, моменты — обратной динамикой по кинематике и реакциям опоры. Это не измерения мышечных сил или максимальных возможностей. Приседания и условия с грузом не являются внешним усилителем в архитектуре и не представляют CPE45.

Для каждого человека обучены три модели по записям без груза всех остальных: постоянная, линейная от угла и линейная от угла со скоростью. Затем оценены записи удержанного человека без груза и с 25 lb. Включены 12 из 12, активные правые флаги и конечные данные: 2335 и 2557 строк после прореживания до 20 Гц соответственно. Усреднение ошибок сначала по каждому человеку, затем по людям. Это проверка переноса между участниками в одной когорте, а не независимая внешняя когорта.

Значения — **числовые единицы исходного CSV, физическая шкала не подтверждена**. Скорость не улучшила точность по заранее заданному критерию; в тесте с грузом небольшая разница направлена в пользу модели угла. Это отрицательный результат для выбранной линейной модели, не доказательство отсутствия динамических эффектов. Нет проспективного ослепления, независимого центра, валидации мышечной силы или клинически значимого допуска ошибки. Различия предпосылок и использование одного набора в обоих условиях ограничивают обобщение. Малый размер выборки и коррелированные кадры учтены ресэмплированием участников, но точность бутстрэпа остаётся ограниченной.

**Единицы — открытый блокер ISS-0028.** README и таблица статьи указывают Н·м, но опубликованный `Code.zip/Plot_3x3_plots.m`, строки 197–210, подписывает загруженные значения Н·м/кг без видимого деления на массу; нормировка при формировании CSV не установлена. README SHA-256 `4a5c8ef0a8d96ed3b81253e7fed2d8516b884fa2aa63e4340c0ab54cf2ac4752`, Code.zip SHA-256 `7e23cb25f81c7c92bb0679646644fc6dae25ad6505c9d5ea4df630dbe9814839`. Решение: не подставлять этот момент в силовой или тканевой гейт до независимого подтверждения масштаба и знаков; парное сравнение ошибок остаётся исследовательским в исходной шкале. Для разрешения нужны авторский код формирования CSV или проверенная пара OpenSim inverse-dynamics и CSV с массой и идентичными временем/стороной.

**Воспроизведение.** `python research/program_evidence_audit/retrieve_squat_data.py <каталог>` выборочно извлекает файлы HTTP Range из 13 378 286 332-байтового ZIP, проверяя размеры и ZIP CRC32. Затем `python research/program_evidence_audit/run_squat_transfer.py <каталог>` проверяет SHA-256 каждого из 96 файлов по [манифесту](SQUAT_DATA_MANIFEST.json). Получен контрольный MD5 архива `3d8e5dbd208da9c0030c6d117e2e33a1` от сервера, но весь архив не скачивался и этот MD5 не проверен. Список файлов и хеши дают воспроизводимый срез, не доказывают достоверность авторской обработки.
