Dear authors,

We are evaluating the openly archived LCMJ20 data described in “Changes in the force-time curve during a repeat power ability assessment using loaded countermovement jumps” (doi:10.7717/peerj.17971). We need no identifying information.

We are conducting computational reanalysis only and will not interpret this short task as a 45-minute or whole-body enhancement trial.
