# EXP-0066 — перенос модели температуры на архив лёгкого велоэргометра

Фиксация 19.11.2026 до вычисления контрастов и ошибок. Были открыты структура двух XLSX, первые четыре строки для проверки формата и метаданные времени. По [статье](https://doi.org/10.1111/sms.70315) входная мощность назначена протоколом. Источник [Zenodo v1](https://doi.org/10.5281/zenodo.19835255) содержит прямые записи пищеводной температуры T_es. Колонки предсказания авторов исключены.

**Исход.** Изменение средней T_es между окнами с центрами в объявленное начало нагрузки и через 300 с. Окна ±15 с, требуется минимум 21 уникальная секундная метка из 31. Только участник, дата и климат с собственной заполненной записью начала нагрузки и последующего ветра. Последняя метка второго окна должна предшествовать ветру. По месяцу/дню и времени совмещать лишь при единственной записи календарного года. Повторы одного человека входят в один кластер. Групповая статистика и сырые личные записи в отчёте имеют разный режим хранения, публикуются только агрегаты.

**Модель и база.** Замороженный Pennes EXP-0063 с номинальной мощностью по статье, массой из метаданных и температурой воздуха по сессии. Начальные состояния прежнего кода. Основной прогноз — изменение температуры ядра от 0 до 300 с. RH в XLSX не указан, поэтому сравнить сценарии 30/50/70% без подбора. На том же исходе сравнить с сохранением температуры, ΔT=0. Для каждой RH среднее MAE по участникам, 95% парный бутстрэп разницы MAE (база минус Pennes, 10 000 повторов, seed 20261119). Проход ограниченного теста требует положительной нижней границы при всех трёх RH. Указать смещение и климатический разрез описательно. Мощность протокольная, начальная температура тканей и действительная RH остаются источниками неопределённости. Это проверка переносимости компонента на лёгкую нагрузку, вне задачи 2700 с и без проверки функционального преимущества.
