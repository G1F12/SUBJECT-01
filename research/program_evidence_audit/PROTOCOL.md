# EXP-0065 — проверка сопоставимой работы и достаточности данных для A

Дата фиксации 19.11.2026. Основание — PLAN, EXP-0061–0064, DEC-0026, ISS-0011–0013, ISS-0021/0023/0025. Поиск новых источников начат до вычислительного прогона. Все сценарии и архивы EXP-0061–0064 уже просмотрены, поэтому опыт представляет вычислительный аудит.

## Проверки и правила решения

1. Повторить пять импортов EXP-0047 и EXP-0061–0064. Артефакты записать во временный каталог. Сравнить JSON структурно, числовую разницу вывести отдельно. Значимые решения и гейты должны совпасть точно. Для округлённых выходов допускается абсолютная погрешность до 0,00001, относительная до 0,000001. Расхождение не исправлять без аудита. Зафиксировать хеши, исходное дерево, версии библиотек.
2. Взять четыре существующие среды и сохранённые D_max при 360 Вт из EXP-0063. Для каждого сценария рассчитать внесённую внешнюю работу точно на шагах исходного решателя. Сравнить с постоянной мощностью 360 Вт и с постоянным выходом, дающим тот же интеграл работы. При изменении шага заново уравнять работу. Вывести мощность/работу, температуры, инвариант теплового баланса, разницу пиков, чувствительность к шагам 5/2,5/1 с. Повторить сравнение с однокамерным балансом при той же теплоёмкости, начальной средней температуре и формуле потерь. Эта база служит проверкой чувствительности к структуре модели. Её температура — объёмная средняя. Не применять к ней порог температуры ядра.
3. Зафиксировать, сохраняется ли знак преимущества прерывистого режима по пику температуры ядра при равной работе на всех шагах. Для отмеченного температурного гейта 39,5 °C ядра и 40,5 °C мышцы вывод считать чувствительным, если классификация меняется с шагом. Это параметры архивной модели. Для эмпирического CPE45 требуются независимые температуры, измеренная механическая работа, моторные исходы, post45 и утверждённые пороги.
4. Для каждого актуального источника отметить фактический доступ, протокол, популяцию и каналы. Полный допуск требует совместных индивидуальных данных. Групповые сводки, смена задачи и недоступные первичные записи допускают только отдельные бенчмарки. Для A/B/C использовать статусы DEC-0021/0026. Итог для A повышается только при наличии измеренного совместного эффекта. Частичные наблюдения остаются отдельными выводами.

## Выход

Воспроизводимый JSON, журнал допуска источников, матрица итогового решения и минимальный контракт будущего внешнего набора. EXP-0065 не включает сбор новых данных, вмешательства и оценку безопасности нагрузки у людей.
