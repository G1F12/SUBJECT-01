# EXP-0073 — аудит временных рядов нагрузки McLaughlin

Гипотеза — постоянный вход мощности из первой минуты может отличаться от записанной мощности за 1–45 мин. Для исходного источника SRC-0086 использовать критерии допуска EXP-0067, присоединение по ID и 44 минутных интервала 1–2…44–45. Основные исходы — полнота записей мощности, отклонение интеграла измеренных минутных значений от постоянной мощности первой минуты и диапазон колебания мощности каждого участника. Предположить, что каждое значение описывает среднюю мощность в одноименном минутном интервале. Проверять интервалы и единицы по заголовкам.

Температура и влажность доступны на редких временных срезах. Указать список временных отметок, полноту и диапазон изменения для тех же людей без интерполяции. Для вычисления интеграла использовать только полностью заполненные ряды, не заменять пропуски. Результаты на ранее просмотренном наборе являются исследовательской проверкой допущения EXP-0067. Сам этот аудит не устанавливает, насколько изменятся температурные прогнозы, и не проверяет CPE45.

После первого прогона обнаружены числовые метки 26–35, 37–39 и 41–60 вместо строковых интервалов. Для дополнительного исследовательского расчёта числовая метка n интерпретируется как конец интервала n−1…n по соседним строкам. Проверяется отсутствие повторов и полное последовательное покрытие. Это предположение требует подтверждения авторами; первый результат при буквальном чтении сохраняется в отчёте.
