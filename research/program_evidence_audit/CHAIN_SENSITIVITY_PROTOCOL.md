# EXP-0068 — чувствительность статического жима к допущениям

Гипотеза — оценка прироста силы платформы в EXP-0061 чувствительна к геометрии и ограничениям контакта. Вход — исходный скрипт и сохранённые параметры сценариев. До расчёта задаются независимые однофакторные сетки для коэффициента трения 0,4/0,6/0,8/1,0, передней границы центра давления 0,10/0,13/0,16/0,19 м, наклона платформы 0/5/10/15/20°, высоты 1,60/1,69/1,78/1,87/1,96 м, а также абсолютного множителя удельного напряжения 0,7/0,85/1/1,15/1,3. Сетки диагностические, не распределения людей.

Основной исход — относительный прирост усилия сценария согласованной цепи относительно базы при одних и тех же изменённых входах. Углы колена 100° и 140° рассматриваются отдельно. Исходный код многосуставного LP исполняется с одной подстановкой параметра, без редактирования исходного файла. Исходное значение должно воспроизводить архив до трактовки. Ошибки решения LP регистрируются. Результат исследует только статическую передачу. CSA, UTS, скорость нагрузки и тканевой предел кода EXP-0062 анализируются отдельно, потому что LP не использует эти параметры. Исход 20% — только порог силы в данной модели. Сеточное число подходящих случаев не является вероятностью.
