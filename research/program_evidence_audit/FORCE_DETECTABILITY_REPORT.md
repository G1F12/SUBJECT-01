# EXP-0100 — обнаружимость +20% силы и проектирование проверки

В [Slade и соавт.](https://doi.org/10.7717/peerj.20848) изучена повторяемость изометрического максимального момента у 18 добровольцев. Для разгибания колена авторы сообщают между днями MD95 **25,9–33,7% от общего среднего** в зависимости от способа расчёта; среднее по методам — 29,7%. Это индивидуальная метрика обнаружимого изменения в конкретном протоколе, не абсолютная граница для жима ногами и не критерий клинической значимости. Показатель группы не тождественен проценту начального уровня каждого человека. Исходные индивидуальные данные в данном расчёте не использованы.

Чтобы показать чувствительность будущего сравнения к масштабу разброса, [протокол](FORCE_DETECTABILITY_PROTOCOL.md) рассматривает только условную схему двух независимых равных групп и односторонний 95%-й нижний предел для контраста изменений. Истинное значение контраста задано как сценарий; это **не прогноз возможного эффекта**. SD изменений каждой группы условно приравнивается к MD95/1,96. Расчёт выполнен по нецентральному t-распределению, целевая мощность теста — 80%.

| Предполагаемый истинный контраст | MD95 25,9%: n на группу | MD95 29,7%: n на группу | MD95 33,7%: n на группу |
|---|---:|---:|---:|
| 20 п.п. | 80% мощности недостижимы на границе | то же | то же |
| 22 п.п. | 541 | 711 | 915 |
| 25 п.п. | 88 | 115 | 147 |
| 30 п.п. | 23 | 30 | 38 |

При истинном контрасте ровно на границе 20 п.п. вероятность пройти строгий тест `нижний предел >20` при сделанных допущениях равна заданному уровню ошибки 5%, независимо от n. Это математическое свойство проверки, а не оценка вероятности успеха программы. Для двустороннего 95%-го интервала нужна иная критическая граница. Проверено, что при каждом конечном n мощность достигает 80%, а при n−1 — ниже.

**Решение:** прежний FORCE20 не изменяется. Для конкретной итоговой проверки заранее измерить повторяемость выбранного многосуставного теста, задать операционное определение контрольного контраста, распределение индивидуальных изменений, интервалы и множественные критерии профиля. Таблица не является рекомендацией размера реальной выборки: параметры из другой задачи не учитывают вариацию отклика, изменение массы, пропуски, кластеризацию, модель контроля и связь с CPE45. Рассчитан только силовой критерий; ткань, моторика, тепло и восстановление не проверены. HOLD и NO_GO сохранены.
