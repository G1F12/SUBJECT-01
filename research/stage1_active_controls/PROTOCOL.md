# EXP-0142 · протокол анализа опубликованных сводок

Базовый коммит `0ce90d115fba4a84d56107c77f8a02f5d0669283`. Правила записаны до расчёта контрастов и их границ. Исходы были известны по публикациям. Это ретроспективный анализ.

1. Сначала ADAPT25. Основной исход — максимальный изометрический суставной момент в неизменной конфигурации, от исходного до последнего общего визита. Активные ноги Arampatzis 2007 и Kongsgaard 2007 сравниваются попарно внутри участника. Ногу с меньшей нагрузкой рассматриваем как активную референсную экспозицию. Фиксируем различия дозы и возможный перенос между ногами. Тренировочный 1RM — вторичный исход. Контроль без силовой работы, как у триатлетов, пригоден для оценки эффекта добавления тренировки, но не как основной референс ADAPT25.
2. Темп — относительное изменение в процентных пунктах за неделю. Для Arampatzis и триатлетов, где опубликованы отдельные pre/post средние, используем отношение средних, с линеаризацией по обеим средним для оценки дисперсии. Это не среднее индивидуальных процентов. Для Kongsgaard используем опубликованные индивидуально нормированные изменения и их SEM. Вычисляем контрольный темп и контраст активных темпов `I−1,25×C`. Оба нижних предела двусторонних 95% ДИ должны быть строго выше нуля. Если неизвестна ковариация, показываем полную допустимую проекцию интервалов, условные срезы и порог корреляции. Не восстанавливаем идентификаторы из рисунков с независимыми распределениями.
3. FORCE20. Для каждого подходящего исхода показываем прирост и изменение с поправкой на изменение референса. Проверяем нижнюю границу относительно +20 п.п. Для отдельной траектории с опубликованными pre/post моментами также используем точный линейный контраст `post−1,20×pre` и его чувствительность к парной корреляции. Сравнение активных ног отвечает за добавочный эффект экспозиции. Для Arampatzis отдельно приводим поправку на независимую группу без тренировки, у которой исходная масса и сила отличаются. Сходство массы pre/post описываем по опубликованным значениям. Отсутствие существенного различия по тесту авторов не заменяет проверку эквивалентности.
4. Неизвестная корреляция двух измерений лежит в [−1, 1]. Для линейного контраста с положительными масштабами это даёт крайние стандартные ошибки как разность и сумму взвешенных маргинальных ошибок. Для контраста парных изменений варьируем также их корреляцию. Максимальная ошибка получается при максимальных ошибках отдельных изменений и противоположной корреляции между ними, минимальная — из расстояния между допустимыми диапазонами ошибок. Для независимых групп суммируем дисперсии и используем консервативное число степеней свободы `min(n_i−1)`. Края — чувствительность к неизвестной структуре, а не интервалы, оценённые по индивидуальным наблюдениям.
5. Для тканей извлекаем деформацию при фактическом максимуме, силовой знаменатель, если он доступен, или свойства при общей силе, если большее усилие не исследовано. Измеренную реакцию отличаем от способности выдерживать заданную повторную нагрузку. Для ADAPT25 нужны данные по траектории, для FORCE20 — данные по тому же усиленному состоянию. Для заключения о достаточном запасе нужны заранее обоснованные критерий и измерение либо независимо проверенная оценка локальной нагрузки и ёмкости. Одна средняя деформация или жёсткость, даже в той же когорте, не позволяет получить запас. Перенос модели из другой конфигурации исключён.
6. Скрининг файлов включает приложения, внешние хранилища и связанные публикации. Для частичных источников сохраняем измеряемый канал, уровень агрегации, границу применимости и причину отсутствия расчёта. CPE45 вне анализа.
7. Для MAT Werkhausen задаём диагностический тест при беге. Соединяем по опубликованному коду участника и визиту, требуем 101 конечную точку на шаг. Для длины считаем размах и разность максимума и длины в конце опоры. Для оценки силы используем максимум модуля, поскольку знак в массиве зависит от фазы опоры. Сначала усредняем шаги внутри визита, затем оцениваем среднее парных изменений и двусторонний t-интервал по участникам. Сопоставляем также форму сигнала, число шагов и набор идентификаторов между каналами. Движение при предпочитаемом темпе относится только к нагрузке в беге.
   У Centner сравниваем опубликованные средние и SD высоконагрузочной и другой активной групп. По числу степеней свободы первичного анализа доступно 36 из 38 завершивших. Если точный n по группам не указан, используем нижние допустимые n (12 и 9) для консервативной оценки ошибки.
8. Для Vesterhus используем индивидуальное изменение KE_MIVC, `100 × (post/pre − 1)`. Соединяем опубликованные CSV по FP и проверяем группу. Основное сравнение — изменения за три цикла, с интервалом Welch для `OCU−1,25×NOC`. Изменение за цикл или сессию служит описанием. Точные даты визитов отсутствуют, поэтому сравнение недельного темпа не идентифицируется. Сравнение наблюдательное, обе группы выполняли сходную силовую работу. Повторяем оценку у тех, у кого есть парная жёсткость и парный SWV. Число участников по каналам показываем отдельно.
9. Для Malliaras первичный исход — изометрический момент, два активных сравнения высоконагрузочной группы с концентрической и стандартной эксцентрической. Для FORCE20 используем также контроль без тренировки. При наличии mean±SD индивидуальных относительных изменений используем их напрямую, включая оценки напряжения, силы сухожилия и деформации при нативном максимуме. Вторичный 5RM оцениваем отдельно. Сигналы потери функции и боли описываем по отчёту авторов.
